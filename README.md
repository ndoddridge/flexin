# Flexin

A simple personal workout tracking web application.

**Concept:** Training Day → Workout Session → Exercise → Set

## Stack

- .NET 9
- ASP.NET Core
- Blazor (interactive server)

## Run locally

```bash
dotnet run --project Flexin
```

Then open the URL shown in the terminal (default: `http://localhost:5295`).

## Current status

Phase 1 — application foundation and shell only. Workout models, SQLite, and tracking features are intentionally not included yet.
